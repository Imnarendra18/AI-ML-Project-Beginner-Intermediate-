## 🚀 Installation

### Prerequisites
- Python 3.8 or higher
- Git
- pip or conda package manager

### Setup Instructions

**Method 1: Using pip (Recommended)**
```bash
# Clone the repository
git clone https://github.com/Imnarendra18/AI-ML-Project-Beginner-Intermediate-.git
cd AI-ML-Project-Beginner-Intermediate-data

# Create virtual environment
python -m venv venv

# Activate virtual environment
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
# Create conda environment
conda create -n ml-projects python=3.9

# Activate environment
conda activate ml-projects

# Install packages
conda install pandas numpy matplotlib seaborn scikit-learn jupyter
📊 Projects

File: notebooks/01_Linear_Regression.ipynb

Dataset: computers.csv

Objective: Predict service minutes based on units repaired

Model visualization

Dataset: std_marks_data.csv

Multicollinearity check

Model interpretation
